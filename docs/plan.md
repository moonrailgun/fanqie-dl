# Go CLI 提取计划

来源：ch6vip/fqapp，固定版本 e43762d0ba9b192b5e8cb7db24a5b6e06f2216e3。

1. 提取搜索、完整目录、CM 批量正文及 DH 单章补取；不包含 Flutter UI、书架、听书和 HTTP 服务。
2. 提供 `search` 和 `download` 命令，接受书籍 ID / 番茄书籍链接，输出 UTF-8 TXT。
3. 每批最多请求 100 章，仅重试未成功的章节，必要时单章补取，再按目录顺序合并。章节缓存支持继续下载；失败返回非零状态，不生成缺章的最终文件。
4. 使用离线 HTTP 测试验证异常、顺序和恢复，使用公开经典作品进行真实搜索、下载与全本检查。

优先 Go 标准库；先验证无需设备注册的接口，只有真实调用需要时才迁移额外签名算法。
